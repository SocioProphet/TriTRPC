# Scoring rubric

## Goal

Score transport approaches in the specific agentic coordination regime this phase-2 work targets.

## Categories

### 1. Hot-path compactness
- lower control-frame bytes is better
- lower repeated semantic overhead is better

### 2. Semantic reuse
- higher inheritance rate is better
- lower semantic re-sending is better

### 3. Coordination expressiveness
- native semaphore semantics
- native barrier or quorum semantics
- explicit artifact commit semantics

### 4. Governance and replay
- explicit epoch handling
- explicit replay or repair signaling
- explicit policy/boundary carriage

### 5. Benchmark honesty
- large opaque payload case does not count as a claimed TriTRPC win unless measured

## Suggested scoring

Use a 0–5 score per category and justify each score with measured evidence or explicit protocol support.
